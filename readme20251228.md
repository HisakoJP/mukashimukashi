## ? 重要な用語

### Git LFS (Large File Storage)
- **役割**: 大きなファイル専用の保管庫
- **仕組み**: 
  - Gitリポジトリには「ポインタ(132バイト)」だけ保存
  - 実体(2.6GB)は別サーバーに保存
- **メリット**: リポジトリが軽くなる

### .gitattributes
```
*.m4a filter=lfs diff=lfs merge=lfs -text
```
- **役割**: 「.m4aファイルはLFSで管理する」という設定ファイル
- **場所**: リポジトリのルート

### GitHub Pages - Deploy方式の違い

#### Deploy from a branch (使ってはいけない)
```
Gitリポジトリ → そのまま配信
音声ファイル: ポインタ(132B) → ? 再生できない
```

#### GitHub Actions (正解)
```
1. Gitリポジトリからチェックアウト
2. git lfs pull で実体をLFSサーバーから取得
3. 実体をGitHub Pagesにデプロイ
音声ファイル: 実体(2.6GB) → ? 再生できる
```
